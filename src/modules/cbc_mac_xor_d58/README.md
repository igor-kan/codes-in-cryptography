# Length-Prefixed CBC-Chain Message Authenticator (`cbc_mac_xor_d58`)

> Category: **Message Authentication** | Language: **C11**

## Overview

Computes collision-resistant length-prefixed CBC-MAC tags over 64-bit block arrays preventing length-extension attacks via prepended block counts.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Prefixing block length strictly separates 1-block and 2-block extensions.
