# Dynamic Offset Decimal Token Extraction (HOTP-Style) (`otp_hmac_counter_d59`)

> Category: **Authentication Tokens** | Language: **C11**

## Overview

Combines secret seed and monotonic counter through keyed compression and performs dynamic 31-bit RFC 4226 masked 6-digit token extraction.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Generated OTP token remains bounded inside [0, 999999] across arbitrary counters.
