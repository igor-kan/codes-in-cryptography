# Speck-128/128 Lightweight ARX Block Cipher & CTR Mode (`speck128_ctr_cipher`)

> Category: **Block Ciphers** | Language: **C11**

## Overview

Implements 32-round Speck-128/128 Add-Rotate-XOR block cipher with on-the-fly key schedule expansion, inverse decryption, and official 2013 paper test vector verification.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Matches official Speck-128/128 KAT test vector bit-for-bit.
- decrypt(expand(K), encrypt(expand(K), pt)) == pt.
