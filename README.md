# Cryptographic Algorithms & Primitives

Implementations of modern cryptographic primitives, post-quantum lattice-based algorithms, zero-knowledge proof components, and constant-time arithmetic routines.

## Focus Areas
- `lattice_crypto`: Learning With Errors (LWE), Ring-LWE polynomial arithmetic, and Kyber-style NTT transforms
- `zero_knowledge`: Pedersen commitments, Schnorr sigma-protocols, and elliptic curve pairing foundations
- `symmetric_ciphers`: Constant-time ChaCha20 quarter-round primitives, Poly1305 MAC accumulators, and Keccak-f[1600] permutations
- `key_exchange`: X25519 Montgomery ladder scalar multiplications and constant-time field arithmetic
- `hash_functions`: BLAKE3 chunk tree hashing, SHA-3/SHAKE sponge constructions, and HKDF expand/extract routines
